# Plan: Add language-based redirect for `/ai` (matching root `/` behavior)

- `/` redirects to `/pt/`, `/en/`, or `/es/` via Cloudflare middleware (`functions/_middleware.ts`)
- `/ai` renders Portuguese content directly (`src/pages/ai/index.astro`)
- `/ai/en` renders English content (`src/pages/ai/en.astro`)
